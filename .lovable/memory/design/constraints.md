---
name: Design constraints
description: Rejected design approaches and hard style rules
type: constraint
---
- NO yellow/amber — looks cheap
- NO green — user explicitly rejected green accents
- NO dark theme — bright cream only
- NO rounded corners — zero border-radius
- NO puzzle icon/logo — use wordmark only: "puzzleai." in Space Grotesk bold, "ai." in accent color
- NO generic SaaS template layouts
- NO background images that compete with text — use CSS-based visuals (dot grids, gradient washes, canvas animations)
- Accent color: warm coral-copper (15 80% 55%) — sophisticated and warm
- Maintain editorial sharpness and magazine-level whitespace
- Every section needs visual texture (dot grids, gradient washes, hover accent lines)
- Hero must have interactive canvas visualization, not static imagery
