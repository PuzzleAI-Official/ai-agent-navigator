    description: WebRTC SDP exchange — browser sends its SDP offer; API returns SDP answer to establish WebRTC peer connection. Requires ephemeral token in Authorization header. Response includes Location header with call_id for sideband WebSocket control.
    request_format: raw SDP text body, Content-Type application/sdp
    python_request_param: data=
    response_format: SDP text (answer); Location header = unique call URL

  - method: WSS
