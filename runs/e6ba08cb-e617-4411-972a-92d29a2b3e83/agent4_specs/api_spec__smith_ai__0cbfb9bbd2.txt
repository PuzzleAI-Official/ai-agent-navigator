    request_format: JSON array of call-request objects. Required fields per object: callback_number (E.164 string), reason (int 1-8), action_required (string ≤500 chars), action_fallback (string). Optional: first_name, last_name, email, attempts (int), cadence_amount (int), cadence_unit (1=minutes/2=hours/3=days), availability (1=24-7/2=business-hours/3=custom), custom_from, custom_to, custom_weekdays (obj), custom_timezone, send_summary_to (email).
    python_request_param: json=
    response_format: JSON confirmation

    description: Add a recipient to an existing Outreach Campaign so Smith.ai agents will call them as part of that campaign. Requires Outreach Campaigns plan API key (separate from VR plan key). Auth via query-string token.
    request_format: JSON object. Required: phone_number (E.164), campaign (campaign ID string). Optional: first_name, last_name, email. Additional data fields can be passed as extra keys for campaign personalization.

    response_format: JSON confirmation
